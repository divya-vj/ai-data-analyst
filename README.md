\# 📊 AI Data Analyst Pro



Professional AI-powered data analysis platform built with Python and Streamlit.



\## 🌐 Live Demo



\*\*Try it now:\*\* \[https://ai-data-analyst-ad3maqemsshlptsrvxebtc.streamlit.app/







\## ✨ Features



\- 📁 \*\*Multi-Format Support\*\*: Upload CSV, Excel, JSON files

\- 📊 \*\*Automatic Data Profiling\*\*: Instant insights on data quality

\- 🔍 \*\*Outlier Detection\*\*: Find anomalies using Z-score method

\- 📈 \*\*Statistical Analysis\*\*: Comprehensive descriptive statistics

\- 🔗 \*\*Correlation Analysis\*\*: Discover relationships between variables

\- ⚠️ \*\*Missing Values Analysis\*\*: Identify and visualize data gaps

\- 💅 \*\*Beautiful UI\*\*: Modern gradient design with responsive layout



\## 🚀 Quick Start



\### Try Online

Visit the live demo link above - no installation required!



\### Run Locally



1\. \*\*Clone the repository\*\*

```bash

git clone https://github.com/divya-vj/ai-data-analyst-pro.git

cd ai-data-analyst-pro

```



2\. \*\*Install dependencies\*\*

```bash

pip install -r requirements.txt

```



3\. \*\*Run the app\*\*

```bash

cd app

streamlit run main.py

```



4\. \*\*Open browser\*\* at `http://localhost:8501`



\## 🛠️ Tech Stack



\- \*\*Frontend\*\*: Streamlit

\- \*\*Data Processing\*\*: Pandas, NumPy

\- \*\*Visualization\*\*: Matplotlib, Seaborn, Plotly

\- \*\*Statistics\*\*: SciPy, Scikit-learn

\- \*\*Deployment\*\*: Streamlit Cloud
